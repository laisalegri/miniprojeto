# Mini-Projeto Avaliativo - Módulo 1 - Semana 07

## Resumo sobre o projeto
Este projeto tem como objetivo desenvolver uma análise exploratória de dados em uma base do Kaggle, afim de praticar os conhecimentos adquiridos até o momento no curso **Carreira Tech - Trilha Análise de Dados - Manipulação de Dados com Python e SQL** do programa SCTEC.

Dentre eles, vamos verificar a qualidade dos dados, fazer a limpeza e identificar se existem inconsistências na base.

Também gerar estatísticas simples e funções de agrupamentos para trazer informações operacionais relevantes e gerar insights para as áreas de negócios, diretoria e gestão estratégica conseguirem tomar decisões assertivas baseadas em dados.

## Passo a passo para clonar o miniprojeto para o ambiente local:

1 - Acesse o **VSCode** abra o terminal e faça o clone do repositório:

`git clone https://github.com/laisalegri/miniprojeto.git`

2 - Abra o arquivo **miniprojeto_lais.ipynb** e rode todas as células.

> OBS: Se você abrir o arquivo **miniprojeto_lais.ipynb** no Google Colab, precisará enviar a base `varejo.csv` manualmente quando rodar a célula do item `2. Carregamento do dataset (base de dados)`.
